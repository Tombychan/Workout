# Atelier Solfège

Application d'entraînement en formation musicale (version autonome, données au 29/10/2026).

Onglets : Lecture (parcours guidé, entraînement libre, partition Vaccai, défilement, mode « Chanter avant d'entendre »), Chanter (imiter, degrés, intervalles, bourdon, mesure de la justesse au micro), Gamme, Intervalles, Rythme, Partitions (Vaccai : Salti di quinta, leçon VII ; explorer, analyse guidée, lire, chanter, ma fiche), Glossaire (94 mots).

- Application : `solfege.html` (à la racine du dépôt) ; ce dossier contient le moteur de partitions et les scans. Aucune installation. Le micro demande une page servie en HTTPS (GitHub Pages convient).
- La progression, les réglages, les fiches et les mots ajoutés sont enregistrés dans le navigateur de l'appareil.
- La version vivante, enrichie par Claude (nouveaux mots, nouvelles partitions), est l'artifact « Atelier Solfège » sur claude.ai ; cette copie est mise à jour à la demande.

Crédits : gravure des partitions par [abcjs](https://github.com/paulrosen/abcjs) 6.7.1 (licence MIT, voir `LICENSE-abcjs.txt`) ; symboles musicaux d'après la police Bravura (Steinberg, SIL Open Font License 1.1). Partitions de Nicola Vaccai (1790-1848), *Metodo pratico di canto italiano per camera* ; scans personnels des éditions Peters et Steingräber.
